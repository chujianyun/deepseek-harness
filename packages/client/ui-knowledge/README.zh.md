# @deepseek-ai/dsh-client-ui-knowledge

[English](README.md) | 中文

## 概述

在 Desktop 侧栏的 Skills 下方新增**知识库**入口及其打开的页面：左侧是当前登录租户的[知识库](../../../docs/glossary.zh.md#knowledge-base)，右侧是选中知识库的数据源；提供新建、重命名、删除知识库的对话框，以及知识库设置和召回测试。它通过 [`knowledgeBases` Remote](../../knowledge/knowledge-base/README.zh.md) 读取和操作，并提供 [`embedding` Remote](../../llm/embedding/README.zh.md) 中的模型供选择。在对话中，它在输入框加入**知识库**按钮，通过 [`knowledgeSelection` Remote](../../knowledge/knowledge-selection/README.zh.md) 选择会话可检索的知识库，并在每条回答下方显示模型检索到的来源。

<a id="use-this-package"></a>
## 使用本包

把浏览器行挂在 Host 的 `knowledge-base` 行旁边，`disabled` 条件与它相同；web-app bundle 在 `desktop` profile 且配置了用户中心时启用这两行。插件只在 Desktop 渲染器（存在 `dshDesktop`）中生效。Host 的 `knowledge-selection` 行使用相同条件挂载。它注入 `remote.knowledgeBases`、`remote.embedding`、`remote.knowledgeSelection`、`sessions` 与 `uiConversation`，以 `knowledge` 注册到 `main` keyed slot，以顺序 6 加入 `sidebar.panellist`，把知识库按钮加入 `conversation.input.left`，把来源加入 `conversation.chat.turnTail`，并为 `knowledge_search` 结果注册一个 Chat 节点定义。

未登录时页面提示登录。登录后列表显示每个知识库及其文件数，在选择其他知识库前默认选中第一个。**新建知识库**打开对话框，填写名称并选择嵌入模型：本地模型（未安装时标注下载完成后可用），以及每个 API 嵌入模型及其提供商；选择 API 模型时提示文档内容会发送到该提供商，没有可用模型时指向「设置 → 嵌入模型」。创建被拒绝的原因在对话框中说明。

详情显示知识库的嵌入模型、模型不可用时的提示、**重命名**和**删除知识库**（删除前需确认），以及分为**文件**、**文件夹**、**网址**、**笔记**四个页签的数据源，每个页签标出数量，列出名称、大小、状态和分块数。失败的数据源显示原因；已完成或失败的可以重新处理，都可以删除。拖到拖放区或通过**添加文件**选择的文件按本机路径加入，路径由 Desktop 预加载从每个文件读取；无法取得路径的文件会给出说明。添加后页面报告添加了几个文件，以及被拒绝文件的原因。

**文件夹**页签通过**添加文件夹**选择（路径取所选文件共同的文件夹，因此无法选择空文件夹）或拖入文件夹来添加。每个文件夹显示路径、文件数、进度和分块数；**展开**按相对路径列出其中的文件及状态，**已跳过 N 个文件**列出不支持的文件和超出上限的文件，前 500 个列出名称，其余只显示数量。重新处理文件夹会重新扫描。**网址**页签输入网址添加；网页显示标题和网址，变得无法访问的网页保留分块数并显示原因。**笔记**页签在对话框中新建和编辑笔记：标题、Markdown 正文和字数统计，超过 1,000,000 字时不能保存；编辑时读取已保存的笔记。

页面按 `revision` 在操作返回的状态与推送的状态之间保留较新的那个，迟到的返回不会让页面回退。

右上角的标签在**数据源**、**设置**、**召回测试**之间切换详情。知识库因更换嵌入模型而重建期间，每个标签都显示已处理的文档数和进度条。

**设置**复刻 Cherry Studio 的知识库设置，不含重排模型，分为四节：文档处理（内置解析，目前唯一的处理方式）、嵌入模型（显示测得的向量维度；选 API 模型时提示内容会发送到该提供商）、分块（智能分段、分隔符、分段大小、重叠大小）和检索（返回文档数 1–50、相似度阈值 0–1）。大小只能输入数字，并遵循 Cherry 的规则：分段大小大于 0，重叠小于分段大小，关闭智能分段时必须填写分隔符。**保存**只提交改动过的设置；**还原**放弃未保存的修改。已有文档时更换嵌入模型会先确认，因为所有文档都要重新分块和向量化，完成前不能检索。分块设置只对之后加入的文档生效；保存后可点**重新处理全部文档**让已有文档也按新设置分块。

**召回测试**按已保存的检索设置用一个问题检索，先显示结果数、耗时和最高分，再按得分从高到低列出命中结果的排名、来源文件与分块序号、相关度和正文。新的检索进行中时保留上一次的结果。召回测试不进入任何会话。

输入框的**知识库**按钮在登录后显示，点击打开租户知识库的勾选列表，并标出重建中或不可用的知识库；列表只显示 `knowledgeSelection.allowedBases()` 允许该会话选择的知识库（每次打开时读取），以及已选中的知识库以便取消，有知识库被会话的智能体排除时会给出提示；选中 N 个时显示**知识库 N**，新会话默认一个都不选，智能体限定了知识库时默认选中这些。勾选或取消立即生效；一轮进行中时列表提示该修改从模型的下一步开始生效，选择被拒绝时显示原因。模型检索过知识库的 Turn 下方，**引用来源**按最佳片段从高到低列出每个被引用的条目一次，显示其知识库、块序号和片段开头。点击文件或笔记会用本机默认应用打开知识库中的副本，副本已不存在时给出提示；点击网页会在浏览器中打开其地址。来源取自日志中的检索结果，因此重新加载后仍然存在。

<a id="model-experience"></a>
## 模型体验

无，因为页面只编辑知识库，输入框按钮只选择知识库；面向模型的工具属于 [`knowledge-selection`](../../knowledge/knowledge-selection/README.zh.md#model-experience)。

#### KV Cache 影响

无影响。

## 已知限制与延期工作

<a id="known-limitations-and-deferred-work"></a>

- **来源打开的是副本** — 点击引用的文件打开的是知识库中保存的副本，而不是添加时的原文件。
