## 概述

在桌面版侧栏「知识库」下方添加 **连接器** 入口及其打开的页面：每个内置[连接器](../../../docs/glossary.zh.md#connector)一张卡片，右上角显示安装控件或[连接状态](../../../docs/glossary.zh.md#connector-status)，以及登录弹窗。它通过 [`connectors` Remote](../../connector/connectors/README.zh.md) 读取和操作。

<a id="use-this-package"></a>
## 使用本包

在 Host 的 `connectors` 行旁边挂载浏览器行，并使用相同的 `disabled` 条件；web-app bundle 在配置了用户中心的 `desktop` profile 中同时启用两者。插件只在桌面渲染进程中（存在 `dshDesktop`）生效。它注入 `remote.connectors`，把页面以 `connectors` 注册到 `main` 键控插槽，并以顺序 7 把入口加入 `sidebar.panellist`。

每张卡片显示平台名称、其官方 CLI 能访问的内容，以及本发行版安装的 CLI 和版本。右上角在 CLI 未安装时显示 `+`，安装中显示转圈（并显示进度条和已下载百分比，全部字节到达后显示 **正在检查…**）。DSH 尚未支持的连接器显示 **即将支持**，CLI 没有本系统构建的显示 **此系统暂不支持**；两者都不提供 `+`。安装失败后，卡片说明原因（下载源不可达、下载校验未通过、无法写入安装目录，或 CLI 无法运行），并再次提供 `+`。

安装完成后，右上角显示当前租户的连接：红点和 **未连接** 加 **连接** 按钮、转圈和 **连接中**、绿点和 **已连接**（下方显示已登录的账号），或黄点和 **异常**（下方显示原因）。**⋯** 菜单提供 **连接**（异常时为 **重新连接**）、已登录时的 **重新检查** 和 **断开**，以及 **卸载**。断开和卸载都需要确认：断开会删除 DSH 为当前公司保存的登录信息并保留 CLI；卸载还会删除所有公司的登录信息，用户自己安装的 CLI 不受影响。打开页面时会检查所有连接。

点击连接会打开登录弹窗，显示飞书的两个步骤（创建飞书应用、授权飞书账号）并标出当前步骤；在 CLI 报告该步骤的地址之前显示转圈，之后显示二维码、**在浏览器中打开** 按钮和地址。对于本页面发起的登录，每一步的地址会在系统浏览器中自动打开一次。**取消连接**、关闭按钮和 Esc 都会取消登录；登录结束后弹窗自动关闭。某一步失败时会在卡片上说明：无法创建应用时提示联系管理员，授权未完成时提示重新连接。卡片状态只来自流式推送的状态；操作的应答只报告拒绝，拒绝信息显示在卡片上方，直到被关闭。

## 已知限制与延期工作

<a id="known-limitations-and-deferred-work"></a>

- **关闭登录弹窗即取消登录** — 不能隐藏弹窗而让登录在后台继续。
