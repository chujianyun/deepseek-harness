# @deepseek-ai/dsh-client-ui-assistants

[English](README.md) | 中文

## 概述

[智能体](../../../docs/glossary.zh.md#assistant)在 Desktop 中的界面：侧边栏的**智能体**入口、它打开的页面（以卡片显示已登录租户的智能体）和每个智能体的详情页、会话行上的智能体标识，以及新会话页工作区那一行最前面的选择器。两者都渲染 [`assistants`](../../assistant/assistants/README.zh.md) Remote 的状态流。

<a id="use-this-package"></a>
## 使用本包

把浏览器行挂在 Host 的 `assistants` 行旁边，`disabled` 条件相同；web-app bundle 在 `desktop` profile 且配置了用户中心时同时启用两者。插件只在 Desktop 渲染器（存在 `dshDesktop`）中生效。它注入 `remote.assistants`，并在 `sessions` 和 `uiWorkspace` 出现后，把页面以 `assistants` 注册到 `main` 键控插槽，把入口以顺序 8 加到 `sidebar.panellist`（在连接器下方），并填充 `conversation.hero.assistant`。

页面显示一个搜索框和智能体数量，每个智能体一张卡片：头像（彩色圆底加名字首字）、名称、描述（为空时显示**暂无描述**），一个名流蓝**对话**主按钮，以及收着**复制**和红色**删除**的「⋯」菜单。搜索匹配名称和描述。空状态统一为图标加一句说明：未登录时提示登录用户中心；没有智能体的租户说明智能体的用途，并给出**新建智能体**主按钮；搜索无结果时提示换关键词。

页头的**新建智能体**打开创建向导，共五步，可**上一步**、**下一步**：起点——日常助手或电商管家模板，或空白；身份与模型——名称（1 到 32 个字符，**下一步**之前校验）、头像、描述和模型；能力底座——只提供**跟随默认**，不提供各个 Agent preset 供选择；能力子集；以及如何称呼用户、偏好语言、备注和背景。选择模板会预填名称、描述和头像。头像可从十六个预设圆底中选，每次显示八个，可**换一批**；也可上传 PNG、JPG 或 WebP 图片，浏览器把它裁成居中的正方形、缩放到 256 像素并编码为 WebP；其他文件类型会被拒绝。模型列表来自 `session.modelCatalog()`，默认为**跟随全局**，选中的模型若有思考级别，会从它的默认级别开始提供选择。**创建**调用 `assistants.createAssistant()`；成功后向导关闭，否则显示 Host 的拒绝原因。Remote 无法提供的模型和 preset 不会出现。

点击卡片的头像、名称或描述会打开它的详情页，内容通过 `assistants.getAssistant()` 读取；页面顶部是**返回智能体列表**，下面的页头重复卡片上的按钮。详情页像向导一样编辑身份与模型字段、能力底座和能力子集，并以标签页编辑四份核心文件——身份、人格、用户信息和工作方法，每份都是纯文本编辑框。能力底座提供**跟随默认**，已指定某个 Agent preset 的智能体还会显示这个 preset，以便改回默认。部署已不再提供的模型或 preset 会标为不可用。**保存**只把修改过的字段通过 `assistants.updateAssistant()` 发出，再读回保存后的智能体，因为改名会改写身份文件；**放弃修改**恢复已保存的值，两者在有改动之前都不可用。**复制**会打开副本的详情页。卡片或详情页上的**删除**会先弹出确认框，写明智能体名称，以及会话列表中有多少个已开始的会话绑定了它，然后调用 `assistants.deleteAssistant()`；已打开的详情页在智能体被删除后回到列表。被拒绝的操作会在卡片上方或详情页页头下方显示消息，直到关闭。

能力子集分 Skill、连接器和知识库三组，每组可选**全部（跟随全局）**或**仅选中**；选仅选中时，以勾选框列出 `assistants.capabilityOptions()` 当前提供的项目，连接器显示为飞书和钉钉。智能体允许、但当前已不再提供（被卸载、关闭或删除）的 id 保持勾选并带**已失效**标签，以便取消。模板会预填它的子集，所以电商管家的连接器默认只有飞书；详情页只有在允许的项目真正变化时才保存子集，与顺序无关。

侧边栏的每个会话行在标题前显示该会话所绑定智能体的头像，取自会话列表的 `assistant` 投影；悬停显示名称，行的悬浮卡片也会多一行**智能体：<名称>**。会话绑定的智能体不在当前登录租户中时，页面会对会话列表里所有这样的 id 调用一次 `assistants.otherTenantAssistants()`（每次登录租户后重新询问），回答之前该行不显示标记。智能体由本机其他租户保存的会话显示灰色 **⇄** 标记，名称为**其他公司的智能体**，不显示该智能体的名称、头像或描述；智能体不在任何租户中的会话显示灰色 **?** 标记，名称为**已删除的智能体**；未绑定智能体的会话，以及未登录时的所有行，都不显示。详情页最后是**最近会话**：该智能体已开始的主会话，按更新时间从新到旧，每行显示标题和距今时间；点击会通过 `uiWorkspace.openSession()` 打开该会话。最多列出十个，并注明一共有多少个。

插件通过 [ui-workspace](../ui-workspace/README.zh.md) 的 `uiWorkspace.registerSessionGrouping` 在侧栏分组方式菜单中注册**智能体**分组，排在第一项。它按会话绑定的智能体分组，组头显示智能体的头像和名称，各组按组内最近的会话排序。未绑定智能体的会话归入**通用模式**。绑定的智能体不在当前登录租户列表中的会话（已删除、属于其他公司，或未登录和首个状态到达之前的所有已绑定会话）归入**其他**，不显示该智能体的任何信息。重命名、删除、切换租户或切换语言都会重新分组。在当前登录租户的智能体可知之前，分组报告自己尚未就绪，侧栏因此保留暂时无法显示的智能体分组的折叠状态；切换到另一个租户会清除前一个租户智能体分组的折叠状态。

选择器显示即将开始的会话所用的智能体：尚未绑定的选择优先，其次是主视图空白会话已绑定的智能体，否则显示**通用模式**——新会话一开始就是这样。它的菜单先列出**通用模式**，再列出每个智能体及其头像和描述。选择（包括**通用模式**）后通过 `assistants.select()` 绑定主视图显示的空白会话；没有空白会话时，选择会等待，并在下一次会话列表变化带来空白会话时绑定。卡片上的**对话**会选中该智能体，并通过 `uiWorkspace.startSession()` 打开新会话页，所以随之出现的会话一开始就绑定了它。其他插件通过可选的 `assistantPicker` 服务选择（插件挂载期间提供）：`pickTemplate(templateId)` 像菜单一样选中由该模板创建的第一个智能体，当前选择或绑定已是该模板的智能体时保持不变，租户没有时返回 false。在主视图之外，或租户没有智能体时，选择器不渲染任何内容。被拒绝的绑定会在输入框上方以提示条显示，并在卡片上方显示消息直到关闭。

## 模型体验

间接通过 [`dsh-assistants`](../../assistant/assistants/README.zh.md#model-experience)：选择会把会话绑定到一个智能体，该服务把它的核心文件加进系统提示词。

#### KV Cache 影响

没有直接影响。

## 已知限制与延期工作
<a id="known-limitations-and-deferred-work"></a>

- **其他公司的回答按登录保留** —— 某个 id 是否由其他租户保存，每次登录租户后只询问一次，所以本机其他进程在那个租户里期间删除的智能体，到下次登录前仍显示为其他公司的智能体。
- **会话数来自已加载的列表** —— 删除确认框统计会话列表中的会话；未打开的会话，其智能体来自投影缓存。
