# Session Sync

[English](README.md) | 中文

## 概述

`@deepseek-ai/dsh-session-sync` 把员工的对话上传到当前 [Hub 登录](../../credentials/hub-account/README.zh.md)所在的用户中心，供员工的其他电脑读取。每个顶层会话连同它的子智能体会话作为一个对话包，在它的每一轮结束后上传；登录后的第一次扫描会上传本机已有的会话。附件按内容摘要只上传一次。删除会话会在用户中心一并删除。失败的请求会重试，离线时记下的删除在重启后照样发出。

<a id="use-this-package"></a>
## 使用本包

把本包作为 Loader 条目挂在 Hub 登录和会话存储旁边；它注入 `hubAccount`、`sessionQuery` 和 `sessionPersistence`，并用 `ctx.get` 读取 `attachments`。web-app bundle 在配置了用户中心的 Desktop 上启用它。它没有 Remote：只要登录了某个公司的员工就在后台工作，未登录时停止。

| 字段 | 默认值 | 含义 |
|---|---|---|
| `requestTimeoutMs` | `300000` | 每个用户中心请求的期限 |
| `dshHome` | `$DSH_HOME` 或 `~/.dsh` | 存放同步记录 `session-sync.json` |
| `deviceName` | 去掉 `.local` 的主机名 | 其他电脑上显示的本机名称 |
| `debounceMs` | `2000` | 一轮结束后的等待时间，连续几轮只上传一次 |
| `scanIntervalMs` | `300000` | 扫描间隔，扫描会上传没有结束一轮却发生了变化的会话，例如改名 |
| `retryMs` | `60000` | 连不上用户中心后重试前的等待时间 |

### 一次上传包含什么

顶层会话指不是子智能体会话的已存储会话；分叉出来的会话本身就是顶层会话。它的对话包是 gzip 压缩的 JSON `{ format: 1, sessions }`：先是该会话的完整日志，再是它下面所有子智能体会话的日志，按 id 排序，每份都带会话头和继承事件数。日志里没有用户消息的会话不上传。其中任何一份日志读不出来时，整个对话包等到能读时再传。上传时附带版本号、工作文件夹（超过 1000 个字符时为 null）、电脑名、最新标题（截到 200 个字符）、绑定的智能体 id、附件，以及最新事件的时间。

附件按事件中任意位置的 `sha256:<hex>` id 找出。服务先询问用户中心缺哪些，再通过会校验字节的附件存储读出并上传，只列出用户中心已有的附件。超过 100 MB、排在前 1000 个之后、本机已读不出、或被用户中心拒收的附件不列入，但对话包里仍然引用它。

### 什么时候上传

一轮结束 `debounceMs` 之后、登录和每次登录账号变化时、每隔 `scanIntervalMs`，以及删除之后，各运行一次同步。每次同步先发出当前登录账号待发的删除。扫描再从新到旧查看每个顶层会话；只有日志字节数（后端不提供字节数时用它的版本标记）自上次读取后变化了才重新读取，只有对话包内容摘要变了才上传。因为没有用户消息或读不出而没上传的会话，变化之前不再读取。刚结束一轮的会话总会被读取和比较。对话包在事件循环之外压缩。版本号从 1 开始，每次被接受的上传加一。

记录文件 `<dshHome>/session-sync.json` 为每个顶层会话保存同步所属账号、上次的版本号、内容摘要、存储变化标记，以及对话包被扣下的原因。改动只有写入成功后才算数；记录缺失、读不出或损坏时按空处理，所有会话都会重新读取和比较。

### 用户中心的回应

| 回应 | 结果 |
|---|---|
| 接受 | 记下版本号和摘要 |
| `409 stale_revision` | 用用户中心的版本号加一重新上传；上传三次后这个会话留到下一次同步，其他会话照常进行 |
| `409 missing_attachments` | 重新检查并上传附件，然后重新上传 |
| `410` | 会话已在其他电脑上删除，不再上传 |
| `400` 或 `413` | 对话包被扣下，内容变化后再传 |
| `403` | 该登录不能同步（不是公司成员），在登录变化前不再同步 |
| 其他回应、没有回应或登录已变化 | 本次同步停止，`retryMs` 后再运行 |

### 账号与删除

账号指一次登录的公司和手机号，对应一位员工。每个会话归属它第一次上传时的账号；登录其他账号时（其他公司，或同一公司的其他员工）不碰它。删除一个同步过的会话会为它的账号记一条待发删除，该账号登录时发出。读取或上传过程中被删除的会话不记录条目，随后发出删除。删除从未同步过的会话不发出任何请求。删除子智能体会话也不发请求；下一次扫描会重新上传它的顶层会话。

<a id="model-experience"></a>
## 模型体验

无，本包只读取会话日志，不向其中写入任何内容；这里的内容都不会进入模型请求。

#### KV Cache 影响

无影响。

## 已知限制与延期工作

<a id="known-limitations-and-deferred-work"></a>

- **只上传** —— 其他电脑通过后续的包读取已上传的对话；本包既不下载，也不删除在其他电脑上删除的本机会话。
- **记不下来的删除会丢失** —— 删除时记录文件写不进去，会话会留在用户中心。
- **请求途中切换登录** —— 每个请求发出前都核对账号；切换登录时已经发出的请求，按发出时的登录完成。
