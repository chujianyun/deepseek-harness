# 推送群路由（固定 · 不随月份变）

推送目标的 chat_id、open_id 不写在本技能里：群和人员会变，而且 open_id 随飞书应用不同而不同，必须是 MO 飞书连接下查到的值。

## 目标从哪里取

1. **定时任务**：任务指令列出的推送目标就是本次的目标，逐个发送，不增不减。
2. **对话中要求推送**：读云文档《AI巡检固化配置》（https://scnntx5zuepg.feishu.cn/docx/E3cXdNjFQoPknUx34NscD0lAnZb）里的推送路由；文档里没有时向用户确认目标，不从历史消息或记忆里猜。

## 目标角色

| 角色 | 说明 |
|---|---|
| 测试群 | 演练、验收先发这里 |
| 天猫一店正式群 | 天猫一店日报 |
| 拼多多正式群 | 拼多多日报 |
| JACK 个人 | 两个平台的日报都发一份 |

## 发送身份与流程

- **发送身份：当前智能体自身**——MO 飞书连接器的 lark-cli 以机器人身份（`--as bot`）发送，消息类型 interactive 卡片；不以任何用户名义发送，不使用任何独立 app 机器人直连脚本。
- 智能体机器人必须已在目标群里；不在群里时发送会失败，如实报告「机器人不在 <群名>」，不改用别的身份。
- 对话中要求推送：先测试群 → 用户确认 → 再正式群。定时任务按指令直接推送。
- 发送前再次核对平台、日期、文案、目标。
- 发送成功判据：`lark-cli im +messages-send` 返回成功且带 message_id；失败时保留预览、如实报告，不报告成功。
