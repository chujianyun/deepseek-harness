# 映射要素与更新规范

## 一、映射要素清单（逐项必须有出处）

### 天猫一店（5.1）

| 要素 | 说明 | 出处 |
|---|---|---|
| 目标表 spreadsheet_token + sheet 名 | 当月目标拆解表 | 用户给的表格链接/文件 |
| 指标行范围与行数 | 如「row2~row18 共 17 个指标行」 | 读表头/首列核对 |
| 日期块起始列 | 如「G 列起为日期块」 | 读首行日期核对 |
| 每日列数与列序 | 如「每 4 列 = 目标/实际/完成率/原因」 | 读日期块表头 |
| 列号公式 | 如「10月N日目标列 = 3+4N」（G 列为第 4 列，0-based 时按实际换算，写清楚基准） | 由列序推算并实测验证 |
| 单位 | 目标/实际量纲（万元等） | 读表核对 |
| 反向指标 | 费比/排名越低越好；花费/费用=辅助项不进需优先关注 | 沿用巡检逻辑，指标增减时与用户确认 |
| 成员/负责人变更 | 指标行对应的负责人（如会员负责人） | 读表核对，变更需用户确认 |

### 拼多多（5.2）

| 要素 | 说明 | 出处 |
|---|---|---|
| 目标表 spreadsheet_token + sheet 名 | 如「10月分解」 | 用户给的表格链接 |
| 实际数据 bitable app_token + table_id | 店铺销额汇总表 | 沿用或用户提供新表 |
| 店铺清单 + 各店 table_id | 12 家店铺映射 | 读 bitable 核对，增减需用户确认 |
| 单位换算 | 目标万元、实际元（÷10000） | 沿用巡检逻辑 |
| 口径 | 只用单日；**永久排除「名流器械保健旗舰店」** | 排除项必须保留 |

## 二、云文档更新命令

配置文档：《AI巡检固化配置》 https://scnntx5zuepg.feishu.cn/docx/E3cXdNjFQoPknUx34NscD0lAnZb

```bash
# 局部读取当前第五节（先读再改）
lark-cli docs +fetch --doc <doc-url> --scope keyword --keyword "第五节"

# 局部替换（str_replace；只动第五节对应平台小节）。动手前先读 lark-cli skills read lark-doc references/lark-doc-update.md，以它为准
lark-cli docs +update --doc <doc-url> --command str_replace --pattern "旧文本" --content "新文本" --doc-format markdown

# 成败判据：看 data.result（success / partial_success / failed）与 data.warnings，不看外层 ok
```

注意：

- str_replace 的 old 文本须先从文档实际内容中读到（含换行与全角标点要一致），不得凭记忆拼。
- 改动多处时分多次 str_replace，每次替换后确认 data.result。
- 禁止 --command overwrite 整篇重写（会丢结构与其他章节）。
- `--content` 默认按 XML 解析；上面用 `--doc-format markdown` 写 Markdown，此时文档中 `<` 在代码块外需转义为 `\<`，代码块内不转义（详见 `lark-cli skills read lark-doc references/lark-doc-md.md`）。

## 三、回读核验要点

1. `--scope outline`：第五节章节结构完整（5.1 / 5.2 仍在，未误删其他节）。
2. `--scope keyword`：逐一命中新映射关键值——目标表 token、sheet 名、列公式（如「3+4N」）、店铺排除项、日期块起始列。
3. 实测：按新映射读一个真实日期的目标值，与用户表格原值核对一致。

## 四、映射格式示例

- 天猫：目标表 `<spreadsheet_token>` sheet `<sheet_id>`「<月>目标拆解-单日」；17 指标行 row2~18；日期块 G 列起，每 4 列 = 目标/实际/完成率/原因；<月>N日目标列 = 3+4N；会员负责人 <姓名>。
- 拼多多：目标表 `<spreadsheet_token>` sheet `<sheet_id>`「<月>分解」；实际表 bitable `<app_token>` 内 `<table_id>`「店铺销额汇总<年>年<月>月」+ 各店铺 table_id（明细见配置文档）。
- 具体 token 只以配置文档第五节为准，本技能不保存任何月份的真实 token。
