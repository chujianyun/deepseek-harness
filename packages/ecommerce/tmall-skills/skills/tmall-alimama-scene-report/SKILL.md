# 万相台营销场景报表

读取天猫店铺在万相台（阿里妈妈）某一天各推广场景的数据。脚本直接调用万相台报表页自己的接口，不点击页面，也不改动任何推广设置。

## 步骤

1. 选账号：按 `ecommerce-accounts` 技能的规则运行 `dsh-ecommerce accounts`，从 `platform` 为 `tmall`、`kind` 为 `merchant` 的账号中选一个。只有一个已登录时直接用，并在回复里写明用的是哪家店；有多个时先问用户；没有可用账号时停下，请用户到 DSH 设置 → 电商账号登录。
2. 取 Node：调用 `load_workspace_dependencies`，用它返回的 `node` 路径运行脚本（员工电脑不需要另装 Node 或 Python）。
3. 在用户的工作区里，用一次 bash 调用运行（`scripts/` 相对本技能目录）：

   ```sh
   "<node>" "<本技能目录>/scripts/alimama-scene-report.mjs" --account <账号 id> --date <YYYY-MM-DD>
   ```

   - `--date` 省略时取昨天（北京时间）；只能取已经过去的日期。
   - `--out <目录>` 指定输出目录，默认是工作区下的 `天猫报表/`。
4. 在最终回复里写明：用的是哪家店和哪一天；各场景的花费、点击、成交金额、成交笔数、投入产出比和合计；摘要里的 ⚠️ 提示（如果有）；以及文件保存的位置。

## 结果与退出码

- `0`：成功。保存 `万相台营销场景报表_<店铺>_<日期>.csv`（每个场景一行：花费、展现量、点击量、点击率、平均点击花费、总成交金额、总成交笔数、成交人数、投入产出比、总成交成本、点击转化率、总购物车数、加购率、加购成本、引导访问潜客占比、人均成交金额、自然流量曝光量、自然流量转化金额）和同名 `.md` 摘要。比率都由原始数值重新计算。
- `2`：数据未就绪。万相台的去重指标（成交人数等）通常要到次日上午 10 点后才算完；取昨天的数据时如果各场景成交人数都还是 0，脚本不写任何文件。如实告诉用户数据还没就绪、稍后再试，不要自己拼凑数字。
- `3`：账号需要重新登录。请用户到 DSH 设置 → 电商账号重新登录，不要换别的店铺。
- `1` / `64`：其他失败或参数错误，把脚本的说明原样告诉用户。

成交数据按万相台的归因口径统计，之后几天可能还会小幅增加；需要和之前的报表对比时提醒用户这一点。

摘要里出现 ⚠️ 自然流量提示时，说明万相台还没算完自然流量，两列自然流量数据暂不可信：如实告诉用户稍后重跑可补齐，不要据此得出“没有自然流量”的结论。

## 规则

- 只读：不要修改出价、预算、计划或任何店铺设置。
- 一次任务只用一个账号；失败时不要自动换店。
