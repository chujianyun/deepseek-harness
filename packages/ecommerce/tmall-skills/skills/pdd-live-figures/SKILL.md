# 拼多多直播取数

读取拼多多店铺某一天的直播数据。脚本直接调用两个后台页面自己的数据接口（商家后台「数据中心 → 直播数据」，多多直播「数据中心」，后者用同一个商家账号自动登录），不点击页面，也不改动任何设置；两个页面之间会停顿几秒，避免触发平台限流。

## 步骤

Windows 上命令行是 PowerShell：以带引号的路径开头的命令前要加调用符 `& `，例如 `& "<node>" "<本技能目录>/scripts/…" …`，否则 PowerShell 不会执行它。

1. 选账号：按 `ecommerce-accounts` 技能的规则运行 `dsh-ecommerce accounts`，从 `platform` 为 `pinduoduo`、`kind` 为 `merchant` 的账号中选。调用方指定了店铺时按店铺名选；有多个可选又没有指定时先问用户；没有可用账号时停下，请用户到 DSH 设置 → 电商账号登录。
2. 取 Node：调用 `load_workspace_dependencies`，用它返回的 `node` 路径运行脚本。
3. 用一次命令行调用运行（`scripts/` 相对本技能目录）：

   ```sh
   "<node>" "<本技能目录>/scripts/pdd-live-figures.mjs" --account <账号 id> --date <YYYY-MM-DD>
   ```

   `--date` 必填，只能是已经过去的日期（北京时间）；多多直播数据中心只保留最近 30 天。
4. 需要保存结果时，把脚本输出原样写进工作区的 JSON 文件，不要改动里面的数。

## 输出

成功时输出一行 JSON：`{"platform", "accountId", "store", "account", "data": {"date", "platforms": [{"platform": "拼多多直播", "date", "metrics", "missing", "notes"}]}}`。`metrics`：

| 键 | 含义 | 来源 |
|---|---|---|
| `直播GMV` | 直播成交额（元） | 商家后台直播数据 |
| `直播支付订单` | 直播支付订单数 | 商家后台直播数据 |
| `直播支付转化率` | 比值，0.0061 即 0.61% | 商家后台直播数据 |
| `人均观看时长` | 分钟 | 商家后台直播数据 |
| `累计观看量` | 当天观看总量（整数） | 商家后台直播数据 |
| `千次进人成交` | 元 | 多多直播数据中心 |
| `直播间涨粉数` | 整数 | 多多直播数据中心 |

`notes` 写明直播间名称和统计日，用来核对是不是这家店、这一天。商家后台没返回某项指标时，该项为 `null`，`missing` 里写明原因；如实转述，不要补数。

## 退出码

- `0`：成功。
- `2`：数据未就绪（商家后台还没更新到这一天，或数据中心没有这一天）。不写任何结果，如实告诉用户稍后再试，不要自己拼凑数字。
- `3`：账号需要重新登录。请用户到 DSH 设置 → 电商账号重新登录，不要换别的店铺。
- `1` / `64`：其他失败或参数错误，把脚本的说明原样告诉用户。

## 规则

- 只读：不要修改直播间、推广或任何店铺设置。
- 一次只用调用方指定的账号；失败时不要自动换店。
