# 分流标签

[English](triage-labels.md) | 中文

将五种标准分流角色映射为以下问题跟踪标签。

| 标准角色 | 问题跟踪标签 | 含义 |
|---|---|---|
| `needs-triage` | `needs-triage` | 维护者需要评估该问题 |
| `needs-info` | `needs-info` | 等待报告者提供更多信息 |
| `ready-for-agent` | `ready-for-agent` | 规格完整，可交由自主 agent（智能体）执行 |
| `ready-for-human` | `ready-for-human` | 需要人工实现 |
| `wontfix` | `wontfix` | 不予处理 |

skill（技能）提到某个分流角色时，使用本表中对应的问题跟踪标签。若要采用已有标签，修改问题跟踪标签列。创建或应用标签时，遵循[问题跟踪规则](issue-tracker.zh.md)中的外部写入授权要求。
