# Agent Note: 基于常驻 Chrome 与页面接口的电商账号

Status: proposed

[English](2026-10-07-ecommerce-accounts-over-store-session.md) | 中文

## 问题

电商管家[智能体](../../../../docs/glossary.zh.md#assistant)需要店铺的真实经营数据：万相台推广报表、生意参谋日数据、公开商品页面。这些平台没有店铺能用的相应 API：数据都在浏览器登录之后，并受设备指纹和风控保护。DSH 如何让这些登录保持有效、技能如何拿到登录后的数据、如何避免抓取用的账号被封，决定了这件事能不能撑过一天。

## 提案

[电商账号](../../../../docs/glossary.zh.md#ecommerce-account)是一个平台账号，带有**自己独立的 Google Chrome 用户数据目录**，由系统安装的 Chrome 启动，通过 CDP 接管。登录态由 Chrome 自己保存；DSH 不保存任何密码或 cookie。

- **浏览器常驻。** 已登录账号的 Chrome 在后台无界面持续运行，DSH 重启后依然存在，DSH 重新接管。淘系核心 cookie 大多是会话级的，每次用完就关的浏览器会丢失登录。
- **用平台自己的响应判断登录。** DSH 打开一个业务页面，截取平台自己的登录接口响应，按各平台的检测表判断；判定登录失效前重试一次。
- **页面接口，而不是界面脚本。** 技能调用平台自己页面所调用的 JSON 接口（万相台、生意参谋）取数，复用页面自己发出的请求模板，并在报告前用独立来源交叉校验数字。
- **两类账号。** [商家账号](../../../../docs/glossary.zh.md#merchant-account)读取本店后台，从不打开公开商品页面；[买家账号](../../../../docs/glossary.zh.md#buyer-account)只打开公开页面。
- **买家号保护由 DSH 强制执行。** 每个买家账号的每日页数额度、平台风控后的冷却，以及自动挑选可用买家账号，都放在 DSH 中，而不是写在技能说明里。
- **技能用 Node，经 Skill Hub 下发。** 第一批天猫技能由现有 Python 改写成 Node 脚本，用 DSH 自带的 Node 运行，并通过 [Skill Hub](../../../../docs/glossary.zh.md#skill-hub) 只下发给需要的租户。

## 考虑过的替代方案

### 为什么不用 Accio 的 RPA DSL 并为它写执行器？

Accio 用自己的 DSL 写逐步操作页面的脚本来驱动各平台，由不在其文件里的内置工具执行。这些脚本归阿里所有且没有许可，DSH 不能分发。它们还要逐步点击页面，并经常固定等待：对 28 份淘系脚本的审计发现，有 12 份的等待中 20%–44% 是固定休眠，导出稍慢就会静默下载到空文件或旧文件。页面接口方案完全跳过点击，并已在同一家店每天于生产中运行。

### 为什么不保存 cookie，或用 Playwright 自带的 Chromium？

导出的存储状态和注入的 cookie 都试过，几天内就会丢失登录或触发二次验证；自带的 Chromium 指纹不对，会卡在滑块验证。带完整用户数据目录的真实 Chrome 表现得就像一个人自己的浏览器。

### 为什么不保留 Python 脚本？

员工电脑不一定装有 Python 及其依赖包。DSH 本身已带 Node，而这些脚本主要是调用接口、解析 JSON 和表格，改写工作量有限。

### 为什么不把买家号限额写在技能说明里？

两个买家账号曾在一天打开约 23 页后被标记身份风险，之后只能容忍约 3 页。模型只要漏守一次就可能损失一个账号，所以由 DSH 强制执行。

## 验收标准

- 添加天猫商家账号时，会用系统 Chrome 打开平台登录页；扫码后账号显示已登录，DSH 不保存任何凭据。
- 退出并重新启动 DSH 后，已登录的账号仍保持登录。
- 买家账号达到每日页数额度或触发风控后，在额度重置或冷却结束前不会再被使用，无论模型如何要求。
- 商家账号从不交给会打开公开商品页面的技能。

## 风险

- **重启。** 电脑重启后是否需要重新扫码尚未验证；第一张票会实测，状态如实显示。
- **平台变化。** 页面接口、请求模板和登录检测表都跟随平台，平台一改就会失效。
- **阈值是经验值。** 每日页数额度和冷却时间来自两个账号的历史，可能需要调整。
- **必须有 Chrome。** 没有系统安装的 Google Chrome，电商账号无法使用。
